# Audits and reviews

Five dated records of checks made on this project, kept as they were written.
An **audit** (a file starting `AUDIT_`, apart from the response) checks the
paper and the results against the code; a
**review** (`REVIEW_`) is an outside review of this repository; the
**response** is the project's answer to the validity audit.

| Date | File | What it is |
|------|------|------------|
| 2026-08-27 | [`REVIEW_2026-08-27.md`](REVIEW_2026-08-27.md) | An outside review of this repository against the paper, with a list of fixes. Its own note says not to quote its numbers, which were measured on a design removed the next day. |
| 2026-08-29 | [`REVIEW_2026-08-29.md`](REVIEW_2026-08-29.md) | A second outside review, with twelve items to fix; its status note records how each was worked. |
| 2026-08-31 | [`AUDIT_2026-08-31_paper_against_code.md`](AUDIT_2026-08-31_paper_against_code.md) | The paper against the code, line by line: every equation, table, figure and numbered section. [`../PAPER_TO_CODE.md`](../PAPER_TO_CODE.md) is the table kept current since. |
| 2026-09-08 | [`AUDIT_2026-09-08_scientific_validity.md`](AUDIT_2026-09-08_scientific_validity.md) | An independent audit run from outside the repository: does the code do what the paper describes, are the reported numbers produced by a valid experiment, and do the choices hold up against the literature. |
| 2026-09-08 | [`AUDIT_2026-09-08_response.md`](AUDIT_2026-09-08_response.md) | The project's answer to that audit, one section per item. It carries the audit's date in its name and was written on 2026-10-02. |

These records are not updated as the project moves on, so their paths are the
ones of the day they were written. Where one names `docs/ASSUMPTIONS.md`, or a
line or section of it, that file was split on 2026-10-03 into
[`../assumptions/`](../assumptions/README.md) and
[`../findings/`](../findings/README.md), one file per entry under the same
codes, so `A-21` is in `../assumptions/A-21.md`. Where one names another of
these five files in `docs/`, it moved into this folder the same day.
